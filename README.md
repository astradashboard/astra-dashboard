# ASTRA Dashboard

Application Windows d'ASTRA CAPITAL : capital des comptes MetaTrader 5 (FTMO et autres prop firms) et calendrier des profits et pertes.

- Installation : voir `LISEZMOI.txt`
- Les mises à jour publiées ici sont installées automatiquement au lancement de l'application (fichier `version.json`).
- Les identifiants et les données des comptes restent sur l'ordinateur de chaque utilisateur.
